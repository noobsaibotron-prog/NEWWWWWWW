# AIEQ+ Repo Map

This index maps the AIEQ+ repository structure.

## /METHOD_BASE
The constitution of the method. Defines principles, vocabulary, and rules.
- `AIEQ_PLUS_METHOD_BASE.md` - Core principles and canonical cycle
- `AIEQ_PLUS_GLOSSARY.md` - Terminology
- `AIEQ_PLUS_PROMOTION_POLICY.md` - Rules for promoting skills

## /RUNTIME
Executable prompt fragments and protocols for the agent while working.
- `AIEQ_PLUS_SYSTEM_PROMPT_CORE.md` - The core system prompt
- `AIEQ_PLUS_RUNTIME_QUICKSTART.md` - Quick operational discipline
- `AIEQ_PLUS_OUTPUT_PROTOCOL.md` - Standard output formats
- `AIEQ_PLUS_BOUNDARY_AND_FLAG_PROTOCOL.md` - Rules for emitting flags

## /TEMPLATES
Infrastructure for creating new skills and tracking tests.
- `AIEQ_PLUS_SKILL_TEMPLATE.md` - Structure for new skills
- `AIEQ_PLUS_TEST_RECORD_TEMPLATE.yaml` - Format for archiving tests
- `AIEQ_PLUS_EVALS_TEMPLATE.json` - Evaluation structure
- `AIEQ_PLUS_CHANGELOG_TEMPLATE.md` - Version history tracking
- `AIEQ_PLUS_SKILL_FRONTMATTER_TEMPLATE.yaml` - Metadata template

## /GOVERNANCE
Formalizes states, criteria, and retirement policies.
- `AIEQ_PLUS_STATUS_MODEL.md` - Governance states (Drafted, Reviewed, etc.)
- `AIEQ_PLUS_WEAKNESS_CLASSIFICATION.md` - Taxonomy of skill weaknesses
- `AIEQ_PLUS_MULTI_SKILL_CONFLICT_PROTOCOL.md` - Handling skill conflicts
- `AIEQ_PLUS_MODEL_DECAY_AND_RETIREMENT_POLICY.md` - Retiring obsolete skills
- `AIEQ_PLUS_HUMAN_IN_THE_LOOP_PROTOCOL.md` - When human intervention is required

## /DOMAINS
Domain-specific specializations (Legal, Medical, Strategy, Finance, Creative, Engineering).

## /EXAMPLES
Complete examples of skills, evals, and tests for training and reference.

## /ACTIVE_SKILLS
Live, operational skills currently in use.

## /RETIRED_SKILLS
Archived skills that are no longer recommended for active use.
