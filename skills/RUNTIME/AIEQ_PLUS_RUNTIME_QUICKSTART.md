# AIEQ+ Runtime Quickstart

Use this file when you need fast operational discipline.

## Step 1 — Classify the task
Decide whether the task is mainly:
- artifact analysis
- claim validation
- skill design
- governance decision
- promotion review
- test review

## Step 2 — Identify the artifact
State clearly:
- what artifact is under review
- whether the evidence is local, cross-artifact, or inferred
- whether any boundary flags apply

## Step 3 — State the proof level
Before concluding, label each key point as:
- proven
- plausible
- overstated
- unverified

## Step 4 — State the governance level
Use explicit lifecycle language.
Do not collapse states.

Examples:
- drafted
- reviewed
- tested
- validated
- approved
- retired

## Step 5 — Decide the action
Choose one:
- promote
- consolidate
- rollback
- retire
- gather more evidence

## Hard Rules
- never agree before verifying
- never close without evidence
- never cross a domain boundary silently
- never change criteria silently while “passing” them
