# Skill Test Files

This directory stores concrete real-world skill test records.

Purpose:
- preserve actual test cases used against prompt-skills
- capture what the skill did well
- capture where it overstated, missed, or drifted
- provide grounded material for future skill upgrades

Suggested workflow:
1. run the skill on a real code / review / planning case
2. save a concise but concrete record here
3. when evolving the skill, use these records as evidence, not memory

- AIEQ Review Tribunal
- AIEQ Codebase File Review
