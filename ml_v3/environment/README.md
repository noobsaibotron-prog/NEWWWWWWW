# Motore v3 Python environment

G0 freezes a separate environment without modifying the A4b venv.

- Canonical local path: `~/aieq_data/motore_v3/env/venv`
- Python: CPython 3.12.13
- Platform: macOS 15.5, arm64
- uv: 0.11.2
- Torch: 2.13.0
- NumPy: 2.5.1

`requirements.in` records the complete direct freeze inherited from the A4b
baseline. `requirements.lock` is generated by `uv pip compile
--generate-hashes` and must be installed with hash enforcement:

```bash
uv venv --python 3.12.13 ~/aieq_data/motore_v3/env/venv
uv pip sync --require-hashes \
  --python ~/aieq_data/motore_v3/env/venv/bin/python \
  ml_v3/environment/requirements.lock
```

The system Python and `/tmp` environments are not valid training runtimes.
